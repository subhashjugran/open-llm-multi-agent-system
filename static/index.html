Open LLM Multi-Agent System

This demo runs a practical agent workflow on top of Ollama. Give it a real task, let the planner break it down, let the researcher gather evidence, and let the executor assemble the final architect-level answer.

Make sure Ollama is running and at least one model has been pulled.

What this demo does

The workflow is intentionally explicit. Instead of one giant prompt, the request moves through four stages: planning, evidence gathering, synthesis, and review. That makes the output easier to debug, audit, and improve.
